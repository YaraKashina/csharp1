# ЛАБОРАТОРНАЯ РАБОТА №1  
## ПРОЦЕДУРНОЕ ПРОГРАММИРОВАНИЕ  

**Вариант** (Задачи 2, 4, 6, 8, 10 в каждом из разделов)  

Программа состоит из двух файлов: `Program.cs` и `Tool.cs`, и предоставляет пользователю интерфейс для работы со всеми разделами задач.  

---

## Как использовать

1. Запустите программу
2. Выберите тему задач (1-4):
   - 1) Методы
   - 2) Условия
   - 3) Циклы
   - 4) Массивы
3. Выберите номер задания (2, 4, 6, 8 или 10)
4. Следуйте инструкциям на экране
5. После выполнения задачи можно выбрать другую задачу или тему

## Описание задач

### **БЛОК 1: МЕТОДЫ**

#### **Задача 2: Сумма знаков**  
Необходимо реализовать метод таким образом, чтобы он возвращал результат сложения двух последних знаков числа `x`, предполагая, что знаков в числе не менее двух.

**Алгоритм решения:**  
Метод извлекает последнюю цифру числа через оператор `% 10`, а предпоследнюю - через `(x / 10) % 10`. Затем возвращает сумму этих двух цифр.

---

#### **Задача 4: Есть ли позитив**  
Необходимо реализовать метод таким образом, чтобы он принимал число `x` и возвращал `true`, если оно положительное.

**Алгоритм решения:**  
Метод сравнивает число с нулём через оператор `>` и возвращает результат сравнения.

---

#### **Задача 6: Большая буква**  
Необходимо реализовать метод таким образом, чтобы он принимал символ `x` и возвращал `true`, если это большая буква в диапазоне от 'A' до 'Z'.

**Алгоритм решения:**  
Метод проверяет, находится ли код символа в диапазоне от кода 'A' до кода 'Z' включительно через операторы `>=` и `<=`.

---

#### **Задача 8: Делитель**  
Необходимо реализовать метод таким образом, чтобы он возвращал `true`, если любое из принятых чисел делит другое нацело.

**Алгоритм решения:**  
Метод проверяет два условия: делится ли `a` на `b` без остатка ИЛИ делится ли `b` на `a` без остатка. Также обрабатывает случай деления на ноль.

---

#### **Задача 10: Многократный вызов**  
Необходимо реализовать метод таким образом, чтобы он считал сумму цифр двух чисел из разряда единиц.

**Алгоритм решения:**  
Метод извлекает последние цифры каждого числа через `% 10`, беря абсолютное значение для отрицательных чисел, затем возвращает их сумму.                                                                                                                                                                                                                             ### **БЛОК 2: УСЛОВИЯ**

#### **Задача 2: Безопасное деление**  
Необходимо реализовать метод таким образом, чтобы он возвращал деление `x` на `y`, гарантируя, что не будет выкинута ошибка деления на 0.

**Алгоритм решения:**  
Метод проверяет, равен ли делитель нулю. Если да - возвращает 0, иначе выполняет деление с приведением типов для получения дробного результата.

---

#### **Задача 4: Строка сравнения**  
Необходимо реализовать метод таким образом, чтобы он возвращал строку, которая включает два принятых числа и корректно выставленный знак операции сравнения.

**Алгоритм решения:**  
Метод сравнивает два числа через условные операторы `if-else if-else` и формирует строку с соответствующим знаком сравнения (`>`, `<` или `==`).

---

#### **Задача 6: Тройная сумма**  
Необходимо реализовать метод таким образом, чтобы он возвращал `true`, если два любых числа (из трех принятых) можно сложить так, чтобы получить третье.

**Алгоритм решения:**  
Метод проверяет все три возможные комбинации сложения двух чисел на равенство третьему через логический оператор `ИЛИ`.

---

#### **Задача 8: Возраст**  
Необходимо реализовать метод таким образом, чтобы он возвращал строку с правильным склонением слова "год".

**Алгоритм решения:**  
Метод определяет последнюю цифру и две последние цифры числа. Для чисел 11-14 всегда возвращает "лет". Для остальных: 1 - "год", 2-4 - "года", остальные - "лет".

---

#### **Задача 10: Вывод дней недели**  
Метод принимает строку с названием дня недели и выводит на экран этот день и все последующие до конца недели.

**Алгоритм решения:**  
Метод использует оператор `switch` для каждого дня недели. Для каждого случая выводит текущий день и все последующие через `Console.WriteLine()`.

---

### **БЛОК 3: ЦИКЛЫ**

#### **Задача 2: Числа наоборот**  
Необходимо реализовать метод таким образом, чтобы он возвращал строку, в которой будут записаны все числа от `x` до 0 (включительно).

**Алгоритм решения:**  
Метод использует цикл `for`, который идёт от `x` до 0 включительно, добавляя каждое число в результирующую строку.

---

#### **Задача 4: Степень числа**  
Необходимо реализовать метод таким образом, чтобы он возвращал результат возведения `x` в степень `y`.

**Алгоритм решения:**  
Метод использует цикл `for`, который выполняется `y` раз, каждый раз умножая промежуточный результат на `x`. Начинает с 1.

---

#### **Задача 6: Одинаковость**  
Необходимо реализовать метод таким образом, чтобы он возвращал `true`, если все знаки числа одинаковы.

**Алгоритм решения:**  
Метод извлекает последнюю цифру, затем в цикле `while` проверяет все остальные цифры числа на равенство этой цифре.

---

#### **Задача 8: Левый треугольник**  
Необходимо реализовать метод таким образом, чтобы он выводил на экран треугольник из символов '*', у которого `x` символов в высоту.

**Алгоритм решения:**  
Метод использует двойной цикл: внешний для строк, внутренний для вывода нужного количества звёздочек в каждой строке.

---

#### **Задача 10: Угадайка**  
Метод генерирует случайное число от 0 до 9 и предлагает пользователю угадать его.

**Алгоритм решения:**  
Метод использует цикл `while(true)`, который продолжается до угадывания. Внутри цикла: генерация числа, ввод пользователя, проверка, подсчёт попыток.

---

### **БЛОК 4: МАССИВЫ**

#### **Задача 2: Поиск последнего значения**  
Необходимо реализовать метод таким образом, чтобы он возвращал индекс последнего вхождения числа `x` в массив `arr`.

**Алгоритм решения:**  
Метод проходит по массиву с конца к началу через цикл `for` и возвращает первый найденный индекс, где элемент равен `x`.

---

#### **Задача 4: Добавление в массив**  
Необходимо реализовать метод таким образом, чтобы он возвращал новый массив с вставленным значением `x` на позицию `pos`.

**Алгоритм решения:**  
Метод создаёт новый массив на один элемент больше. Копирует элементы до позиции вставки, вставляет новый элемент, затем копирует оставшиеся.

---

#### **Задача 6: Реверс**  
Необходимо реализовать метод таким образом, чтобы он изменял массив `arr`, записывая его задом-наперед.

**Алгоритм решения:**  
Метод использует цикл, который проходит до середины массива, меняя местами элементы с начала и конца.

---

#### **Задача 8: Объединение**  
Необходимо реализовать метод таким образом, чтобы он возвращал новый массив, содержащий элементы обоих массивов.

**Алгоритм решения:**  
Метод создаёт массив размером `arr1.Length + arr2.Length`, копирует в него сначала все элементы первого массива, затем все элементы второго.

---

#### **Задача 10: Удалить негатив**  
Необходимо реализовать метод таким образом, чтобы он возвращал новый массив, содержащий все элементы исходного массива кроме отрицательных.

**Алгоритм решения:**  
Метод сначала подсчитывает количество неотрицательных элементов, создаёт массив этого размера, затем копирует в него только неотрицательные элементы.
